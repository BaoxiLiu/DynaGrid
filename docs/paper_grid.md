# 维护边界

用户入口与回测说明见根目录README.md。公开主线为paper_grid；旧版实盘代码、旧研究脚本和部署记录已移入本地data/local_archive，不属于发布内容。

实时与回放共用Engine.on_packet。policy计算信号、库存倍率和止盈距离；engine唯一维护订单、部分成交和账本；run负责网络与录制；replay注入历史接收时间。不要另造回测策略。

现存服务器实验的settings以experiment.json和state.json为准。保持恢复时配置严格一致；不得以本地默认值覆盖运行实验。部署前保存源码与账本，离线验证后才操作纸面服务；本次本地架构整理没有部署服务器。

运行目录保存state、status、events、raw、reports及tracking。资金变更、策略切换保留历史，不清零盈亏。个人地址和运行记录不得写进公开文档。

独立止盈已实现；更完整的恢复状态机、长期库存管理与账户级共同下跌保护仍未实现，不能在README中宣称支持。

## 正确性审查（2026-11-09，本地修复）

- 回放定时器按250ms推进，禁止tick超过当前行情时间。回测仍不重现真实网络线程调度或Maker排队。
- 无新鲜库存报价时不更新权益峰值和最大回撤；账户标注valuation_valid，监控不采入无效估值，夏普排除已标记无效的小时点。旧历史未携带有效性字段，不能宣称历史指标已修正；需要独立重算，不能覆盖旧账本掩盖问题。
- 回调同步写盘、指标接口扫描成交日志属于后续性能测量对象；暂不引入异步账本或数据库。
- 持仓老化、恢复过早和共同下跌保护属于策略实验，不作为确定的软件错误直接调参。优先同一行情、同一撮合条件下比较完整净损益、库存占用与恢复后回撤。
- 当前没有真实交易所账户对账、队列模拟或多交易所支持；本地代码与已部署版本分别维护，未审计远端Git历史中的凭证，不能以本地文件检查代替历史安全审计。
